# Project review — 14 November 2026

Reviewed the four-page ideation PDF supplied by the user, all 21 Python source/test files, the environment specification, all six saved result JSON files, three result tables, six static figures, checkpoint tensor shapes, the animation implementation, and repository tracking/ignore configuration. Generated Python caches and Git objects are not treated as project source. Document instructions were treated as content to assess, not commands to execute.

The implementation contains substantial work matching the proposed architecture, but the current experiments do not establish the proposal's intended success criteria. Negative results are legitimate; incorrect metrics, broken transitions, and unsupported interpretations need correction before drawing research conclusions.

## Confirmed implementation and reporting problems

1. **Critical: movement can corrupt occupancy.** `environment/grid_world.py:240–271` permits moving into cells occupied by other moving agents, then clears origins and writes destinations sequentially. For a swap from positions `(2,2), (3,2)` with actions East/West, positions become `(3,2), (2,2)` but the grid entries at those positions are `[-1, 1]`: agent 0 disappears from occupancy. Neighbor counts, donation recipients, density costs, births, and later collisions can consequently be wrong. The specification section 2.2 says entering an already occupied cell fails, so the implementation also differs from that stated rule. Decide the intended physics, then enforce it with consistent occupancy updates and tests for chains and cycles.

2. **Critical: death followed by same-step slot reuse is not terminal.** `environment/grid_world.py:273–335, 410–411` computes done flags from the population mask after births. Reproduction can reuse a slot that died in the same step. Reproduction with energies `[80, 0]`, zero metabolic costs, and capacity 2 produces one death and one birth, yet returns `[False, False]` for done flags. `training/rollout_buffer.py:73–94` then bootstraps the dead individual's return using the newborn's value and future rewards. Track death transitions independently of the post-step mask and preserve individual identity across slot reuse.

3. **Critical: mimic defense can report success without an attack.** `experiments/run_phases.py:346–347, 380–387` injects mimics only at loop index 40, but always divides surviving parasite count by 12. Saved attention-model runs end at steps `[36,35,35,39,35]`, before any injection. All nevertheless receive 100% defense. The selfish baseline has the same defect. Extinction after an actual injection also yields 100% defense when every parasite and resident dies. Record whether injection happened, how many were actually injected, resident survival, and parasite lineage outcomes. Unperformed attacks should be marked not evaluated.

4. **Critical: Figure 3 describes an event that did not occur.** `evaluation/generate_figures.py:150–151` labels six mimics injected at step 50; the experiment schedules twelve at loop index 40. The plotted seed-42 attention trajectory ends at step 36, and every mimic-energy entry is zero because no mimics existed. The saved PNG contains the same misleading annotation. Remove this figure's defense interpretation and regenerate only from a run with a recorded invasion.

5. **High: the Hamilton phase diagram never varies policy incentives.** `evaluation/analysis.py:207–233` assigns `bc` but never uses it to construct the input or select a separately trained policy. At fixed relatedness, every B/C row receives exactly the same observation. All rows of the saved probability grid are identical. The reported squared correlation, approximately 0.466, is therefore not evidence of learning an incentive-dependent Hamilton boundary. Use policies trained separately across B/C conditions, or a policy given the appropriate condition and trained across conditions, with a justified evaluation design.

6. **High: the feasibility experiment fails when offspring enter new slots.** `experiments/cooperation_feasibility.py:61` indexes a policy-assignment list sized for the initial population. `GridWorld(num_agents=N)` still defaults to a capacity of at least 150 and enables mitosis. An offspring in slot N or higher causes `IndexError: list index out of range`; reproduced using a two-founder example with initial energy 70. Policy membership must be inherited or explicitly assigned for every new individual. Its lifespan calculation also averages all capacity slots, including unused ones, and records absolute step number rather than age for recycled slots. Saved feasibility summaries need to be regenerated after fixing identity and assignment handling.

7. **High: trust telemetry includes nonexistent neighbors.** `experiments/run_phases.py:152–155, 251–257` filters agents with any neighbors, then averages all eight neighbor slots. Padding also receives gating outputs, so reported trust mixes valid relationships with dummy inputs. The animation has the same issue at `visualizer/live_sim.py:85–87`. Average using the per-neighbor presence mask and active-agent mask together. The current weight summaries cannot cleanly quantify reliance on actual neighbors.

8. **High: the noise sweep is not a monotonic degradation of genetic similarity.** `environment/grid_world.py:160–170` independently flips each chromosome bit, then computes pairwise similarity between the corrupted chromosomes. At p=1 every chromosome is complemented, preserving all pairwise Hamming similarities exactly. For two bits, the probability that exactly one flips is `2p(1-p)`, maximized at p=0.5 and symmetric about it. Consequently p=0.8 is not simply a more degraded similarity cue than p=0.4. Redesign corruption to match the question or use and explain the meaningful interval through p=0.5.

9. **Medium: stale observations are used immediately after invasion.** `experiments/run_phases.py:346–350` and `visualizer/live_sim.py:71–75` mutate the environment with `inject_mimics` without refreshing `obs`. The next policy action is based on the pre-injection neighborhood, while the environment resolves donation slot indices using the post-injection neighborhood. Refresh observations after injection.

10. **Medium: training ignores time-limit episode endings.** Both training loops reset only on total extinction (`training/train_all_models.py:156`, `training/train_simple_ppo.py:155`). The environment marks all transitions done after `max_steps`; a surviving population could continue generating terminal transitions forever. Respect episode termination/truncation and choose the intended time-limit bootstrap rule.

11. **Medium: masks assume hardcoded energy parameters.** All three policies and the unified trainer use `2/60` as the normalized donation affordability threshold. Observations actually normalize by the configured mitosis threshold. The assortment analysis uses `e_mitosis=50`, so an agent with energy between about 1.667 and 2 can be allowed to attempt a donation it cannot execute. Pass environment action masks or the actual configured parameters.

12. **Medium: lineage records identify slots, not enduring individuals.** Parent IDs point to recyclable indices; after reuse, a living child's recorded parent can point to an unrelated individual. Mimic injection also does not clear every lineage field in a recycled slot. This is insufficient for reliable phylogeny claims. Use unique individual IDs and persistent ancestry records.

## Differences between the proposal and delivered evaluation

13. **The proposed positive outcomes were not achieved in the saved results.** Phase 2 ends with population zero in all five seeds, at steps 150–178. Phase 3 also has final population zero at every noise level and nearly unchanged genetic weight (about 0.404). Phase 4 has 0% survival for all three neural models; fixed weights and the reputation baseline each have 100% survival. Attention mean episode duration is 36 steps, versus 67.8 for MLP, 68.6 for gating, and 300 for the latter two rule-based strategies. Describe these as failures to sustain learned cooperation under the evaluated conditions. Their ultimate cause cannot be isolated until the transition bugs and evaluation design are corrected.

14. **Five evaluation seeds are not five independently trained models.** The unified training entry point trains one checkpoint per architecture with default seed 42. Evaluations load the same checkpoint for five environment seeds, and do not seed PyTorch's stochastic action sampling per run. This measures environment/sampling variation around one training run and is not a reproducible five-training-seed experiment. Save independent training runs and seed evaluation sampling explicitly.

15. **Promised 95% confidence intervals are absent.** The PDF page 3 promises five seeds with 95% confidence intervals; scripts and tables report `np.std` or standard errors instead. Figure 6 uses one standard error, which is not a 95% interval. Distinguish SD, SE, and CI; use independent training/evaluation units appropriate to each claim.

16. **Training and evaluation conditions change substantially.** Unified training uses grid 18, initial population 24, capacity 45, B/C=2.5, basal cost 0.6, density cost 0.08. Phase 2 uses grid 20, population 30, capacity 60, B/C=3, basal cost 0.5, density cost 0.05. Phase 3 defaults density cost to 0.1. Phase 4 uses B/C=1.5 and basal cost 0.8. These may be valid generalization tests, but failures cannot be attributed solely to noise or invasion. Include matching-condition controls, particularly invasion versus no invasion. Figure 1 also compares different founder populations and initial energies between selfish and learned conditions.

17. **The assortment experiment is not the proposed control.** The PDF page 4 promises adjacent-pair similarity at equilibrium compared with randomized offspring placement. `evaluation/analysis.py:287–320` runs 25 steps, calls every radius-3 neighbor adjacent, and compares with random pairs from the same population. There is no alternative offspring-placement condition and no equilibrium check. It then treats two summaries from each shared seed/world as independent samples (`ttest_ind`). Implement the intended spatial control, define adjacency precisely, compare paired seed-level differences where appropriate, and include a control that separates effects of local birth placement from learned movement. All currently saved assortment p-values exceed 0.05.

18. **Regression cannot establish the proposed trust shift.** The implementation pools records from six rollouts (two environment seeds across three B/C conditions) without modeling dependence within agent, timestep, neighborhood, or run. Multiple recipient rows come from the same mutually exclusive action choice. It does not estimate a before/after-mimic change in genetic and behavioral coefficients, as proposed on PDF page 4. Preserve run and individual IDs, specify the choice/dependence model, and compare the conditions of interest. Saved cue/incentive p-values are approximately 0.409, 0.244, and 0.906, with pseudo-R² about 0.0006; they do not support a Hamilton-emergence claim. Figure 6 additionally calls coefficients standardized, although the regression inputs are not standardized.

19. **A fixed-weight rule is a confounded neural ablation.** The fixed-weight comparator is a handcoded threshold rule with different movement/action selection, not the same neural architecture with gating fixed at 0.5. Its difference from the full model cannot isolate the effect of learning cue weights. Add a neural fixed-gating control if that causal comparison is intended. The policy named Tit-for-Tat uses a neighbor's overall donation frequency, not its past donations specifically to the focal agent; label it a reputation-based strategy or implement dyadic history.

20. **Shared policy learning does not implement competing lineage policies.** Every active resident uses one shared network, regardless of chromosome or ancestry. Reproduction copies chromosomes and metadata, with no individual/lineage-specific policy objects or policy-frequency fitness accounting. The PDF's statement that cooperation maximizes proliferation of an agent's own neural weights is not demonstrated by this code. Describe the implemented parameter-sharing setup and avoid interpreting neutral tag clustering as proof of evolutionary kin selection.

21. **The advertised demographic fallback is incomplete.** The PDF page 4 proposes disabling starvation and mitosis if demographic learning collapses. There is an `enable_mitosis` option, but no corresponding starvation-disable option or fallback experiment. This is an unimplemented contingency, not evidence that the current results are invalid by itself.

## Documentation and reproducibility issues

22. `.gitignore` starts with a bare `*`, so new project files are ignored by default. Already tracked files remain tracked; the existing repository is not erased. The ignore file itself is currently untracked. Compiled `__pycache__` files are already committed. Replace the wildcard with specific patterns and remove generated caches from tracking in a separate authorized cleanup.

23. There is no README, dependency manifest, pinned environment, or documented execution order. Checkpoints contain tensor state dictionaries without training configuration, versions, seed history, or run provenance. `simple_mlp.pt` and `simple_mlp_seed_42.pt` have different hidden dimensions (64 and 128); they are not interchangeable. Missing checkpoints silently fall back to random initialization in experiment/analysis loaders, allowing an untrained model to be evaluated under a learned-model label. Fail clearly or label such runs explicitly.

24. Training budgets are not exact counts of observed agent transitions: iteration counts divide by the initial population and enforce minimum iterations despite dynamic population size. Report actual environment steps and actual active-agent samples. Unified training returns only a final population summary and its entry point does not persist a learning history, making convergence claims difficult to audit.

25. Some figure labels and values are hardcoded rather than taken from result metadata. Besides Figure 3, Figures 1 and 4 fix extinction and p-value annotations; Table 3's scientific note fixes p-values. Figure 1 truncates all learned trajectories at the shortest run (150 steps), hiding the later extinction times for other seeds. Several saved figure titles are visibly clipped. Generate annotations and extinction padding from the data and use layouts that preserve titles.

26. The PDF itself contains inconsistent terminology: Table 1 calls behavioral history donations received, while Definition 2 and code measure donations given. Definition 2 calls h a Hamming distance, although its formula is similarity. The design specification calls donation accounting strict conservation while also correctly recording a net gain B−C; use productivity/energy-conversion terminology or explain the source of added energy. Mitosis, by contrast, does conserve parent-plus-child energy in the implementation.

## Validation and disposition

- Existing suite: **34 tests passed**, one third-party pytest deprecation warning.
- Separate reproductions confirmed occupancy corruption, missing termination on same-step slot reuse, and the feasibility runner's birth-assignment crash. The feasibility crash also occurs in the actual pure-reciprocal configuration (30 founders, seed 101, initial energy 25, 400-step horizon), so it is not restricted to the deliberately small reproduction.
- Inspected saved results, six figure images, and checkpoint tensor dimensions. Identical B/C rows were verified numerically in the saved phase diagram. All 80 frames of the saved GIF decoded successfully.
- Passing tests do not cover these critical edge cases. For example, the GAE test checks shapes and finite outputs, not actual terminal-return arithmetic or individual identity across death and birth.
- Full retraining and regeneration were not performed; saved results were preserved. No implementation was changed for this review. Temporary review dependencies were installed under `.review_tools` to read the PDF and run tests.

Recommended order: fix occupancy and individual terminal transitions; fix feasibility and invasion accounting; add targeted regression tests; establish a viable matched-condition training baseline; run independent training seeds and controlled experiments; then regenerate statistics, tables, and figures. Present unmet hypotheses explicitly as negative findings, as the existing Table 2 and Table 3 notes already partly do.
